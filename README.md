# Reliability Gateway Frontend

Enterprise AI infrastructure website and operator console for [Reliability Gateway](https://github.com/wulgresearch-spec/dataplane-gateway).

Built with Next.js, React, TypeScript, and Tailwind CSS, using deep navy `#1C3052` and ice blue `#EDF3FB`.

The initial frontend implementation is developed on the [`develop` branch](https://github.com/wulgresearch-spec/reliability-gateway-frontend/tree/develop) and will be merged into `main` after review and CI verification.
